# Luvia 13.35.0 / Core 4.35.0 — Memory Studio Motion Rebuild

## Ziel
Memory Moments und Memory Journeys werden nicht länger als künstliche 3D-/WebGL-Kulissen inszeniert. Der Schwerpunkt liegt nun auf einem hochwertigen, fotozentrierten Story-Studio mit abwechslungsreichen Übergängen, sicheren Textflächen und einem Bearbeitungsprozess, der sich an modernen Social-Story-Editoren orientiert.

## Änderungen
- Fotozentrierte Fullscreen-Szenen statt prozeduraler Minecraft-artiger Renderkulissen.
- Sechs unterschiedliche Übergangstypen: Zoom, Dissolve, Lift, Perspective, Iris und Drift.
- Memory Journey als geführtes Story-Studio: Intro, Reisetage, Moments, Reisegefühl, Stimmen, Final Cut, Text & Stil, Premiere.
- Memory Moment als eigener kompakter Studio-Flow.
- KI-Titel und KI-Text sind getrennte Aktionen und verwenden weiterhin `memory.compose` mit lokalem, belegorientiertem Fallback.
- Texte liegen immer auf kontrollierten, kontrastreichen Flächen.
- Cover und Wichtigkeit werden deutlich und konsistent markiert.
- Keine sichtbaren Scrollbars im Studio.
- Galerie, Upload-Pipeline, Realtime, Places und Foursquare bleiben unverändert.
