# Luvia 13.28.1.1 – Smart Photo Clustering

## Sichtbares Frontend
- Gemeinsame Fotomomente als Collage-Karten
- Filter für Momente, Screenshots und Dokumente
- Titel direkt bearbeiten
- Typ korrigieren
- Cluster auflösen oder mehrere Cluster verbinden

## Core
- Zeitcluster: maximal 20 Minuten Abstand
- Ortscluster: maximal 300 Meter, sofern GPS vorhanden
- Zusammenführung von Fotos verschiedener Teilnehmer
- Persistente Korrekturen über `media_clusters` und `media_cluster_items`
- Keine KI-Bildanalyse; ausschließlich Metadaten und nachvollziehbare Heuristiken
