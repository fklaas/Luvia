# Luvia Core 4.0.3.1 · Build 13.0.3.1

## Restaurant Experience Rework

- Restaurant suggestions persist across detail and workspace navigation.
- Restaurant discovery has a compact, responsive search field with accessible overflow behavior.
- Favorites and saved restaurants are grouped in collapsed library panels.
- Saved cards and suggestion cards use a calmer, less dense visual hierarchy.
- Schedule Intelligence receives an optimistic restaurant event immediately after saving planning data.
- Dashboard schedule widgets update through the existing schedule event without waiting for another page load.
