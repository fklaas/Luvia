Luvia 3.2.1 – Modul-Isolation

- Neue modulare Reisen starten mit null ausgewählten Modulen.
- Leere Modulauswahl wird nicht mehr als „alle Module“ interpretiert.
- Normale Reisen zeigen ausschließlich explizit ausgewählte Module.
- Geschützte Vorlage „Paris · Offizielle Reise“ im Erstellungsassistenten.
- Bestehende echte Paris-Reise 31.07.–02.08.2026 wird automatisch als offizielle Komplettreise erkannt.
- Modulauswahl responsiv, kompakter und intern scrollbar.
- Leere Modulkonfiguration kann lokal und in Supabase gespeichert werden.
- Module liegen weiterhin einzeln unter modules/content; index.html ist das gebaute Deployment-Artefakt.
