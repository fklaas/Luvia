# Luvia 11.0.0 · Core 3.0.0 — Modular App Shell

- Alter Dashboard- und App-Shell-Start vollständig vom produktiven Boot getrennt.
- Neutraler Boot-Zustand verhindert das Aufblitzen alter oder neuer Zwischenansichten.
- Neues festes Dashboard als Startseite jeder aktiven Reise.
- Horizontaler Modul-Dock mit Dashboard und Restaurants.
- Restaurants ist das einzige produktiv registrierte Reisemodul.
- Neue zentrale Module Registry im Core.
- Alte Dashboard-Auswahl und alte Modulauswahl werden nicht mehr gestartet.
- Onboarding enthält die Modulauswahl bereits bei der Reiseerstellung.
- Reiseziel wird über den vorhandenen Google-Places-Gateway vorgeschlagen und strukturiert gespeichert.
- Einladung wird nach der Reiseerstellung direkt mit Code, Link, Teilen und QR-Code geöffnet.
