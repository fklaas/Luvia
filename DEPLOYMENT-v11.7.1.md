# Deployment 11.7.1

1. Vorherige Migrationen 013 und 014 müssen installiert sein.
2. `supabase db push` ausführen oder Migration 015 im SQL Editor starten.
3. `supabase functions deploy luvia-gateway` ausführen.
4. Projektdateien deployen.
5. Mit `?v=11.7.1` öffnen und den Service Worker aktualisieren.
