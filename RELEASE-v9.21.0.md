# Luvia v9.21.0 — Core V2.12.3.1

## Destination-Aware Restaurant Search

- Destination Resolve trennt jetzt kanonisches Stadtziel und optionalen Landmark-Kontext.
- Destination Context Schema auf Version 5 erweitert.
- Places Text Search nutzt Stadt-Viewport beziehungsweise Landmark-Bias.
- Distanz wird serverseitig zum kanonischen Stadtzentrum oder Landmark berechnet.
- Gateway unterstützt zusätzliche Nachfilter für vegetarische Eignung, Mindestanzahl Bewertungen und Maximalentfernung.
- Sortierung nach Relevanz, Entfernung, Bewertung oder Bewertungsanzahl.
- Restaurantmodul enthält Bewertungs-, Öffnungs-, Vegetarisch- und Sortieroptionen.
- Keine neue parallele Places- oder Destination-Architektur.
