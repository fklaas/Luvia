# Luvia 13.28.6.7 / Core 4.28.6.7

## Mobile Gallery Width Recovery

- Eliminates horizontal page overflow at 320–760 px viewport widths.
- Hero, download/upload actions, favorites, photo cards, clusters and travel-day tiles now stay inside the viewport.
- Favorite cards use a responsive two-column grid instead of a horizontally scrolling strip.
- Photo actions wrap safely on narrow devices.
- Dialogs use the full mobile viewport without creating page-level horizontal scrolling.
- The PWA install service no longer suppresses the browser install prompt without immediately showing a custom prompt, removing the Chrome console warning.
