# Luvia 13.31.0 / Core 4.31.0 – Memory Worlds Experience Studio

## Ziel
Memory Moments und Memory Journeys werden zu zwei klar unterschiedlichen, gemeinschaftlichen Erlebnissen.

## Memory Moments
- cineastischer Einstieg und horizontale Bildsequenz
- großer responsiver Rich-Text-Editor
- mehr als 50 Reaktionen und Emojis
- deutlich vielfältigere Titelrunden, einschließlich AI Memory Bridge
- klare Trennung zwischen gemeinsamem Herzbild und persönlichem Lieblingsbild
- Story Studio mit zwölf Umschreibungsstilen
- interaktives Bilderbuch mit animierten Sprechblasen der Reisenden
- Vorlagenstudio für Story, Reel, Beitrag, TikTok, WhatsApp, Wrapped und digitales Bilderbuch

## Memory Journeys
- eigenständige Reisebuch-Ästhetik mit sichtbarem Kapitel 1
- Tageskapitel mit Bild, Rich-Text und wiederholbarer KI-Unterstützung
- KI-Kontext enthält vorhandene Bild-URLs, EXIF-/Zeit-/GPS-/Ortsdaten und gespeicherte Bildanalysen; die tatsächliche visuelle Interpretation hängt von der konfigurierten Provider-Capability ab
- Memory Moments werden als bebilderte, anklickbare Stationen dargestellt
- alle Reisenden und fehlenden Perspektiven sind permanent sichtbar
- Reise-Atelier mit Orten, Stimmungen und Stimmen
- Luvia Wrapped als animierte Rückschau
- Social- und Buchformate als vorbereitete Entwürfe

## Stabilität
Galerie, Upload-Batching, Cluster-Realtime, Places und Foursquare wurden nicht verändert.
