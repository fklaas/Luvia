# Luvia 13.32.0 · Core 4.32.0 — Memory Cinema Director

Memory Moments and Memory Journeys were rebuilt as two distinct cinematic experiences.

## Memory Moment
- intimate full-screen scene flow instead of a page wizard
- animated cold open, filmstrip, collaborative voice scene, photo/voice weighting, title cloud, Story Lab and Premiere
- importance weighting drives highlight selection for exports
- animated speech bubbles from fellow travellers

## Memory Journey
- route-like cinematic opening and day reel
- day stories with AI context from available EXIF/GPS/location/vision evidence
- visual Memory Moment doors inside the journey
- collaborative traveller voices, director highlight cut, journey Story Lab and Luvia Wrapped

## Creation and export
- functional Story/Post PNG rendering
- functional vertical WebM film rendering for Reel/TikTok/Wrapped
- system share for generated video when Web Share + file sharing is supported
- no fake direct-post buttons; export formats create real files

## Safety / architecture
- gallery pipeline, gallery realtime and clustering logic untouched
- existing Memory Album/Journey tables reused; weighting stored in metadata
- no new SQL migration
