# Luvia Core 4.0.3 / Build 13.0.3

## Cross-Module Recommendations

- Neues zentrales `LuviaCrossModuleRecommendations` mit den Slots „Für euch“, „Gerade jetzt“, „In der Nähe“, „Auf eurem Weg“, „Danach“ und „Alternative“.
- Restaurantmodul lädt beim Öffnen selbstständig kontextbezogene Vorschläge; eine initiale Suche ist nicht mehr nötig.
- Suche, Favoriten und gespeicherte Restaurants wurden nach der Luvia Design Language neu strukturiert und deutlich entschlackt.
- Der Restaurant-Workspace wurde von vier überladenen Reitern auf eine kompakte Planung mit optionalen persönlichen Details reduziert.
- Favoriten lassen sich öffnen und direkt entfernen.
- Dashboard reagiert auf Schedule-Intelligence-Änderungen und übernimmt geplante Zeiten unmittelbar.
