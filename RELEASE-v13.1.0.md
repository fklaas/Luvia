# Luvia Core 4.1.0 · Build 13.1.0

## Today Intelligence

Build 13.1.0 introduces the central deterministic Today Intelligence service and replaces the simple dashboard schedule list with an intelligent day companion.

Implemented:
- canonical Today snapshot model
- current, next, upcoming and completed classification
- departure advice with travel and buffer estimates
- free-window detection
- hard and soft schedule conflicts
- deterministic day-load classification
- dashboard timeline, contextual actions and animated states
- offline Today snapshot persistence
- realtime recalculation on schedule, timeline, visit and connectivity changes
- service-registry and Core diagnostics integration
- context-aware PWA diagnostics result

No database migration or Edge Function deployment is required.
