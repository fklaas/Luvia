# Regressionstest · Luvia 12.0.0

## Restaurant-Suche

1. Restaurants öffnen.
2. Standort freigeben.
3. Eine Suche ausführen.
4. Auf jedem Treffer Match, Entfernung, Öffnungsstatus, beste Zeit, Reservierung, Baby-Kontext und Budget prüfen.

## Detailansicht

1. Einen Treffer öffnen.
2. Positive Gründe und Gegenargumente prüfen.
3. Besuchszeit, Geh-/Fahrzeit, Gruppen-Match und Teilnehmerwerte prüfen.
4. Alternativen und konkrete Vorschläge prüfen.
5. Speichern, Favorit, Tagesplan und Reservierung testen.

## Gespeicherte Restaurants

1. Restaurant speichern.
2. Modul erneut öffnen.
3. Intelligenz-Badges auf der gespeicherten Restaurantkarte prüfen.

## Dashboard

1. Zum Dashboard wechseln.
2. Widget „Restaurant Intelligence“ prüfen.
3. „Restaurant für heute“, Nähe, Reservierung, Abfahrt und Alternative prüfen.
4. Über den Widget-Button das Restaurantmodul öffnen.

## Developer Console

1. Developer Console öffnen.
2. Service `recommendations` testen.
3. Service `restaurant-intelligence` testen.
4. Beide müssen erfolgreich oder bei fehlender Reisedatenbasis nachvollziehbar eingeschränkt reagieren.
