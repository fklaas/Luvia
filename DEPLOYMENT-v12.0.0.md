# Deployment · Luvia 12.0.0

1. Den vollständigen Inhalt dieses Projektordners in das Repository übernehmen.
2. Commit und Push durchführen.
3. Das Pages-/Cloudflare-Deployment abwarten.
4. Die App einmal mit Cache-Busting öffnen:

   `https://myluvia.app/index.html?v=12.0.0`

5. Bei einer installierten PWA die App einmal vollständig schließen und erneut starten.

Für diesen Release sind keine neue SQL-Migration und kein neues `luvia-gateway`-Deployment erforderlich.
