# Testplan Luvia 10.2.0

1. Neue Reise mit Name, Ziel, Symbol, Farbe und Zeitraum erstellen.
2. Nach Erstellung müssen Einladungscode, Link, Teilen und QR-Code erscheinen.
3. Dashboard muss direkt als erster Screen erscheinen und Name sowie Reiseziel anzeigen.
4. Reise im Profil bearbeiten; Ziel muss nach Reload erhalten bleiben.
5. Module auswählen, speichern und Reload durchführen; Auswahl muss erhalten bleiben.
6. Abgewählte Module dürfen nicht in der Navigation erscheinen.
7. Einladung aus Dashboard und Profil öffnen.
8. Auf Mobilgeräten Dashboard, Modulauswahl und Einladung prüfen.
9. Cache muss `luvia-shell-v10.2.0` verwenden.
