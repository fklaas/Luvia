# Luvia 13.1.3.3 – Stable Schedule Editing & One-Tap Suggestions

- Existing Today entries open the persisted planning workspace.
- Schedule time changes update the same trip-place instead of creating a new entry.
- Restaurant display names remain stable through lifecycle updates.
- Free-time suggestions can be added to the day plan with one click at a calculated suitable time.
- Today rendering no longer performs decorative animations and avoids full-dashboard renders for unchanged trip metadata.
