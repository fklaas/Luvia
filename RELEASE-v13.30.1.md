# Luvia 13.30.1 / Core 4.30.1 – Memory Worlds Foundation

## Produktmodell

Luvia trennt Erinnerungen jetzt sauber in zwei Ebenen:

- **Memory Moment**: eine einzelne automatisch erkannte Szene aus einem Foto-Cluster.
- **Memory Journey**: die vollständige Reise aus Reisetagen, Memory Moments, Einzelbildern und Beiträgen aller Reisenden.

## Memory Journey

Die vollständige Reise wird in sieben weichen Kapiteln wiedererlebt:

1. Rückkehr – cineastischer Einstieg in die gesamte Reise.
2. Reisetage – automatisch vorgeschlagene Kapitel mit eigenen Titeln und Tagesgefühlen.
3. Momente – Memory Moments und einzelne Zwischenbilder werden in die Tage eingeordnet.
4. Perspektiven – jeder Reisende trägt seinen eigenen Blick auf die Reise bei.
5. Name – wechselnde emotionale, verspielte und freche Reisetitel.
6. Geschichte – Tage und Perspektiven werden zu einer gemeinsamen Erzählung verbunden.
7. Bewahren – Abschluss der gemeinsamen Memory Journey.

## Zusammenarbeit

Memory Journeys speichern Beiträge pro Reisendem separat. Niemand überschreibt den gemeinsamen Text eines anderen. Die gemeinsame Geschichte entsteht aus den individuellen Perspektiven.

## Stabilität

Die stabile Galerie-, Upload-, Bild- und Realtime-Pipeline aus 13.29.4 bleibt bestehen. In der Galerie wurden nur sichtbare Produktbegriffe von Fotomoment/Cluster zu Memory Moment angepasst.
