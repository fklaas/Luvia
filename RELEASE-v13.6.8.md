# Luvia 13.6.8 – Global Favorite System

- Ein einziger globaler Favoriten-Writer für alle Place-Typen.
- Favoriten können über jede Mini-, Favoriten- und Detailkarte gesetzt und entfernt werden.
- Alle entfernen verwendet exakt denselben Core-Pfad.
- Alle sichtbaren Karten werden unmittelbar synchronisiert.
- Keine deaktivierten Favoritenbuttons mehr.
- Canonical Place IDs und Cloud als einzige Wahrheit.
