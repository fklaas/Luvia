# Testplan Luvia 11.0.0

1. Seite neu laden: Bis zur fertigen Runtime darf kein altes Dashboard aufblitzen.
2. Ohne Reise: Reise erstellen öffnet das neue fünfstufige Onboarding.
3. Ziel eintippen: Places-Vorschläge erscheinen; Fortfahren ist nur nach Auswahl möglich.
4. Restaurants ist im Modulschritt vorausgewählt.
5. Nach Erstellung öffnet die Einladung; anschließend erscheint das neue Dashboard.
6. Unterer Dock zeigt Dashboard und Restaurants.
7. Wechsel zu Restaurants mountet nur das Restaurantmodul.
8. Wechsel zurück unmountet Restaurants und zeigt das Dashboard.
9. Reload erhält Ziel, Farbe, Symbol, Zeitraum und Modulauswahl.
