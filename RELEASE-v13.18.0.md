# Luvia 13.18.0 / Core 4.18.0

## Journey Knowledge Graph & Universal AI Orchestrator

Dieser Build verbindet zwei aufeinander aufbauende Architekturphasen:

1. **Journey Knowledge Graph**: cloud-autoritative Auflösung von Timeline, Places, Trip-Place-Verknüpfungen, Restaurants, Reservierungen, Teilnehmern und Evidence.
2. **Universal AI Orchestrator**: mehrstufige, providerunabhängige KI-Orchestrierung über eine universelle Read-Only Tool Registry, Domain- und Capability-Verträge sowie nachvollziehbare Evidence.

Das Dashboard-Briefing erhält nicht mehr nur einen reduzierten UI-Snapshot. Es kann sämtliche geplanten Cloud-Einträge einschließlich verknüpfter Restaurants und Reservierungen verwenden. Relevante Core-Events invalidieren den Journey Cache und lösen eine neue Briefing-Berechnung aus.

Die KI darf ausschließlich fachlich validierte Place-Kandidaten ordnen. Place Contracts, Zielgebiet, Providerfakten, RLS und Move-ohne-Timeline bleiben verbindliche Grenzen.
