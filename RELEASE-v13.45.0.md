# Luvia v13.45.0 / Core 4.45.0

## SevenRooms Adapter Foundation + Console Error Cleanup

### SevenRooms
- Provider adapter `LuviaSevenRoomsProviderAdapter` added.
- Supabase Edge Function `booking-provider-sevenrooms` added.
- SevenRooms remains `partner_required`; no live API access is fabricated.
- Publicly verified SevenRooms capabilities are limited to the flexible/open API surface, restaurant booking API and channel management.
- Public status vocabulary / webhook / polling contracts are not guessed. Automatic status application remains disabled until a verified partner contract exists.
- Expected partner-required states use HTTP 200 with `ok:false, expected:true` so they do not appear as transport failures.

### Console / request reliability
This build fixes the causes of the recurring Luvia-originated red request cascades rather than merely hiding console output.

- Schedule cloud reads no longer run before a real authenticated Supabase session exists.
- Duplicate schedule boot refreshes were removed.
- Schedule no longer retries the same unauthorized request three times.
- Schedule writes/deletes are gated by session + network readiness.
- Production SQL reasserts PostgREST grants and RLS policies for `trip_schedule_events`.
- Collaboration RPCs are gated by the actual Supabase session instead of only a UI auth flag.
- Production SQL reasserts collaboration RPC grants and table privileges.
- Presence/activity refresh enters a bounded degraded/offline state instead of repeatedly hitting Supabase while connectivity is unavailable.
- Backend requests proactively refresh near-expiry JWTs before calling `luvia-gateway`.
- Backend calls are stopped locally while the browser is offline or the network circuit is cooling down.
- Transient network failures open a short circuit instead of spawning repeated failed requests.

### Scope note
Browser-extension errors such as `No listener: tabs:outgoing.message.ready` are not generated by Luvia and cannot be removed by Luvia application code. The cleanup in this release targets Luvia/Supabase requests visible in previous console captures.
