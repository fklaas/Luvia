# Testplan — Luvia 13.37.2 / Core 4.37.2

## Pflicht: Voting-Inhalt
1. Voting eines Stapels öffnen.
2. Foto-Kandidaten müssen das echte Foto als Thumbnail zeigen.
3. Story-Kandidaten müssen ihren tatsächlichen Text zeigen.
4. Signal-Kandidaten müssen Emoji/Typ plus Kontext zeigen.
5. Budgetanzeige muss „Noch X von Y Punkten verfügbar“ bzw. „Alle Y Punkte vergeben“ anzeigen.

## Pflicht: Mehrbenutzer-Ergebnis
1. Reisender A vergibt Punkte und speichert.
2. Stapel zeigt verständlich, dass noch eine Stimme fehlt.
3. Reisender B vergibt Punkte und speichert.
4. Bei A muss nach Realtime/Reload „Eure Auswahl steht fest“ erscheinen.
5. „Ergebnis ansehen“ öffnen.
6. Rangfolge, Gesamtpunkte und Einzelstimmen müssen stimmen.
7. Gleichstand darf nicht künstlich aufgelöst werden.

## Pflicht: Card Content Fit
1. Längere Story Card öffnen.
2. Text, Footer, Gewichtung und Album-Aktionen dürfen nicht abgeschnitten sein.
3. Hero-, Story- und Signal-Cards auf Laptop/Desktop vergleichen.
4. Radiale Anordnung darf trotz variabler Höhen keine starken Kollisionen erzeugen.

## Pflicht: Story-Qualität
1. Kurzen Gedanken (z. B. wenige Wörter) fürs Album auswählen.
2. Er darf nicht automatisch als Punkte-Kandidat erscheinen.
3. Eigene Karte öffnen → „Erinnerung ergänzen“.
4. Eine echte Mini-Geschichte mit mehreren Sätzen speichern.
5. Danach muss sie als Album-Kandidat zugelassen werden.

## Header
Geöffneten Stapel prüfen: Datum klein im Kontext, Stacktitel separat als Hauptüberschrift.
