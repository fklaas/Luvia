# Luvia Core 4.0.3.3 / Build 13.0.3.3

## Restaurant Interaction Polish

- Suchleiste responsiv korrigiert; kompakter Suchbutton und vollständig sichtbarer Eingabetext.
- Modul-Intro bleibt mindestens 1,1 Sekunden sichtbar und blendet anschließend weich aus.
- Tagesplan-Aktion öffnet jetzt einen Dialog für Datum und Uhrzeit und übergibt den Termin direkt an Schedule Intelligence.
- Dashboard erhält den geplanten Termin sofort über den optimistischen Schedule-Upsert und anschließend über den Remote-Refresh.
- „Warum passt das?“ ist kontrastreich und lesbar.
- Reisefarbe prägt Modulhintergrund, Suche, Karten, Aktionen und Dialoge deutlich stärker.
- Match Scores werden bei unbrauchbaren 55-%-Fallbackwerten erneut deterministisch aus Rating, Bewertungen, Entfernung, Features und Präferenzen berechnet.
