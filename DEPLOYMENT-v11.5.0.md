# Deployment Luvia 11.5.0

1. Vollständiges Paket in das Repository übernehmen.
2. Commit und Push durchführen.
3. Cloudflare Pages vollständig abwarten.
4. Alle geöffneten Luvia-Tabs schließen.
5. App neu öffnen und Build `11.5.0`, Core `3.3.0` kontrollieren.
6. Bei sichtbarem Altstand einmal `force-update.html` öffnen oder Website-Daten/Service Worker aktualisieren.

Keine SQL-Migration erforderlich.
Kein Supabase-Gateway-Deploy erforderlich.
