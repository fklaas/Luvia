# Luvia v13.0.4.5 — Diagnostics Local Boot Isolation

Core 4.0.4.5 / Build 13.0.4.5.

- Developer Console und Core-Diagnose starten in einem lokalen Diagnosemodus.
- Kein Auth-Refresh, kein Gateway-Aufruf, keine Realtime-Subscription und kein automatischer Provider-Refresh beim Seitenstart.
- Vollständige Services bleiben registriert; Remote-Prüfungen erfolgen nur nach ausdrücklicher Nutzeraktion.
- Der normale App-Boot bleibt unverändert.
