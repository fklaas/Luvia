# Luvia 13.19.1 / Core 4.19.1

## Planned Visits & Functional Briefing
Timeline entries are authoritative planned visits. Bookings are optional separate evidence and their absence is never a warning. Dashboard briefings receive and enumerate the complete planned-visit context.

## Conversational Discovery Core
Places and Move now share one conversational, free-text-first discovery session with dynamic follow-up questions, global profile context and temporary moment preferences. The previous fixed slide flow is no longer the primary entry.

## AI Search & Evidence Pipeline
AI produces multiple search plans; Google Places remains the source of real entities. Place Contracts validate every candidate before ranking. Results are deduplicated, evidence-enriched, uncertainty-aware and personally ranked.
