# Luvia 13.3.0 – Guided Journey Entry

**Core:** 4.3.0  
**Build:** 13.3.0

## Ziel

Der öffentliche Einstieg von `myluvia.app` wird erstmals zu einem eigenständigen, herzlichen Luvia-Erlebnis. Nicht angemeldete Personen landen nicht mehr direkt in einem Login-Formular, sondern verstehen zuerst, wofür Luvia steht und können mit einem ersten Reisegedanken in den Guided Journey Flow starten.

## Enthalten

- neue responsive Public Landingpage
- offene, warme Luvia-Markenwelt
- dezente schwebende Gedankenformen
- verständlicher Reise-Lebenszyklus von Idee bis Erinnerung
- direkte Einstiege für Reisebeginn, Einladung und Anmeldung
- erste Guided-Journey-Frage: „Woran denkst du gerade?“
- vorgegebene Gedanken sowie freie Texteingabe
- natürlicher Übergang vom ersten Gedanken zur Registrierung
- bestehende Supabase-Registrierung und Anmeldung wiederverwendet
- kein localStorage und keine neue lokale Persistenz
- In-Memory Entry State als klar abgegrenzte Grundlage für Build 13.3.1
- SEO-Basis, Responsive Design, Reduced Motion und semantische Dialoge

## Bewusste Abgrenzung

Build 13.3.0 legt noch keine Reise aus dem Gedanken an. Der erste Gedanke bleibt während des aktuellen Einstiegs im Arbeitsspeicher. Die dauerhafte Cloud-Übernahme in eine neue Reise folgt mit Build 13.3.1 – Journey Creation Flow.
