# Luvia 13.1.1.1 — GPS Distance & Today Diagnostics Fix

Core 4.1.1.1 synchronisiert die globale GPS-Position mit dem zentralen Travel Context. Entfernungen in Restaurant- und Cross-Module-Empfehlungen werden damit aus der aktuellen Geräteposition berechnet. Die Profileinstellungen zeigen Position, Genauigkeit und Aktualisierungszeit und bieten eine manuelle Neuladung. Der Today-Intelligence-Smoke-Test akzeptiert auch einen gültigen leeren Tageszustand.
